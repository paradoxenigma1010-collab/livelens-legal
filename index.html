LiveLens

Unified Live Streaming Tool

🚀 Beta Testing Phase

LiveLens is a powerful, privacy-focused streaming application for Android that brings together camera feeds and IPTV playlists in one unified interface. Whether you're monitoring security cameras, watching live broadcasts, or browsing webcams, LiveLens provides a seamless viewing experience.

📹 Camera Streaming

RTSP, HLS, HTTP-FLV, and DASH protocol support for security cameras and webcams

📺 IPTV Playlists

M3U playlist support with EPG (electronic program guide) and Xtream Codes integration

🌐 Stream Browser

Auto-detect stream URLs from websites with built-in browser and smart detection

🎬 VOD Support

Browse movies and series from Xtream Codes providers with lazy-loading catalogs

🔒 Privacy First

All data stored locally on your device. No tracking, no analytics, no cloud storage

⚙️ Powerful Features

Custom categories, favorites, EPG auto-matching, screenshot capture, and more
